# PERL accessibility evidence

## Status and scope

PERL targets WCAG 2.1 Level AA for the synthetic clinician workspace and the on-screen clinician report. This file records engineering evidence as of August 14, 2026. It is not a declaration of conformance. Independent assistive-technology testing, PDF accessibility work, and testing with clinicians who use accessibility features remain release gates.

The current scope covers:

- summary review, safety acknowledgement, revision, approval, and handoff preparation;
- clinician, care-coordination, payer, and administrative audience switching, preview boundaries, and selected-format print actions;
- review queue and record opening;
- blind calibration inputs, Candidate Trial planning, and rating controls;
- matched workflow timing assignment, scored-source review, summary composition, submission status, and evidence thresholds;
- governance, Marketability Map, Decision Room, Permission Ledger, independent-review dossier, named-site admission dossier, Governed Authority Trust, Pilot-Start Interlock, Governed Clinical Release, isolated recovery, local rollback compatibility, operational-monitoring, and incident-response rehearsal evidence/actions, study safety, and change-control views;
- all native modal dialogs;
- the on-screen clinician report, its print action, and the standalone clinical/counsel language-review book.

## Implemented evidence

| WCAG area | Current implementation | Verification |
|---|---|---|
| Structure and names | One primary main region; named view regions; ordered headings; named navigation; real buttons, inputs, tables, lists, tablist, tabs, tabpanels, dialogs, status, and alert regions | Browser accessibility-tree inspection and `tests/accessibility.test.mjs` |
| View navigation | Every view has a programmatic heading target. Navigation moves focus to the new heading. Mobile navigation is hidden from the focus and accessibility trees while off canvas, moves focus into the active item when opened, and returns focus on Escape | Browser focus inspection and source invariant test |
| Queue operation | Each record has a native, named “Open record” button. Table rows are no longer made into simulated keyboard buttons | Browser accessibility-tree inspection and source invariant test |
| Tabs | One tab is in the tab order. Left Arrow, Right Arrow, Home, and End change the selected tab, its panel, and focus | Live browser keyboard exercise and source invariant test |
| Dialogs | All eleven dialogs have an accessible name, an intentionally focusable title, native modal behavior, non-validating dismiss controls, and opener focus restoration | Live browser open, dismiss, and focus-restoration exercise plus source invariant test |
| Focus appearance | Links, buttons, form controls, tabs, cards with hidden native inputs, upload controls, search, and custom controls receive a high-contrast visible focus treatment | Stylesheet invariant and browser visual inspection |
| Target size | Primary controls, icon controls, dialog close, row open, ratings, feedback choices, and secondary study actions use at least a 44 by 44 CSS-pixel target where the interaction permits it | Stylesheet invariant |
| Text contrast | Light-surface microcopy uses `#53605c`, which measures 6.51:1 on `#fffefa` and 5.82:1 on `#f4f1e9`. The light-surface focus ring is at least 3:1. Dark-surface focus uses the gold token against deep green | Executable contrast calculations in `tests/accessibility.test.mjs` |
| Motion | CSS removes animation and smooth scrolling when reduced motion is requested. JavaScript navigation and safety jumps also switch to instant scrolling | Source invariant test |
| Responsive layout | The workspace has single-column breakpoints, scroll-contained data tables, stacked dialogs and report content, and a mobile off-canvas navigation state | Existing desktop/mobile visual QA and responsive stylesheet review |
| Approval clarity | The decision control says “Approve clinician summary.” It does not imply pilot or production release. Handoff status denies attachment, and the Permission Ledger action seals only a blocked snapshot | Source invariant test and live browser inspection |

Run the executable checks with:

```bash
npm test
```

## Release rule

Automated checks and this engineering review may support development. They do not authorize clinical use. A named accessibility owner must accept the completed manual matrix and any exceptions, and the pilot decision group must receive that evidence with the other clinical, legal, privacy, security, recovery, and reliability gates.
